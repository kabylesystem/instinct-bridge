How to export from Bitwarden

In the Bitwarden web vault, open Tools → Export vault. Choose JSON (Encrypted), then Password protected. Account-restricted backups cannot be opened here.

Authy on iPhone: what is required?

Authy has no official export button. A separate, experimental local capture can recover encrypted backup tokens. It requires temporary proxy and certificate setup on your iPhone, followed by removal. This app does not change your phone settings.

The iPhone capture has not yet been validated on a real device for this project. Import both sources together to pair 2FA automatically. Existing entries with different fields are left unchanged.

Exports and passwords stay in memory. Use “Forget data” or close the server when finished.
